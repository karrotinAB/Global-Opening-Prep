# 로그인 화면 캐릭터

`c01.png` ~ `c16.png` = 아트박스 진열창 그림에서 캐릭터를 하나씩 오려낸 것 (배경 투명).
로그인 화면 아래 흰 띠에 왼쪽부터 차례로 서 있고, 살짝 위아래로 움직이며, 마우스를 올리면 폴짝 뜁니다.

- 순서·크기·띄우는 높이는 `index.html`의 `.login-chars` 안 `<img>` 줄에서 바꿉니다.
  - `--h` = 그림 높이(px, 그대로 두기) · `--b` = 원래 그림의 바닥선 기준 높이(음수 = 발이 바닥선 아래, 풍선 든 캐릭터는 양수) · `--d` = 움직임 시작 시간
- 캐릭터를 빼려면 그 `<img>` 줄을 지우면 됩니다. 파일이 없으면 그냥 안 보입니다.
